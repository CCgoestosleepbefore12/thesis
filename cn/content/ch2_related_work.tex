\chapter{相关工作}\label{ch:related_work}

本章按本文方法的逻辑层次综述相关文献，呼应\cref{sec:problem_statement} 提出的三类挑战：\cref{sec:ftc} 与\cref{sec:pomdp_methods} 对应"部分可观测性"，介绍传统控制理论与部分可观测决策的经典框架；\cref{sec:residual_rl}、\cref{sec:robust_rl_dr}、\cref{sec:il_hil} 对应"部署条件约束"，从机器人 RL 残差结构、鲁棒 RL 与域随机化、模仿学习与人在回路三条线索给出本文真机部署的方法基础；\cref{sec:safe_rl} 对应"人机协同安全"，给出安全 RL 与 Reward hacking 背景，为\cref{sec:backup_reward} 备份策略奖励演化分析提供概念支撑。本章侧重领域景观与方法定位，不重复\cref{ch:task_policy}–\cref{ch:real_chapter} 的具体配置细节。

\section{机器人容错控制（FDI/FTC）}\label{sec:ftc}

故障检测、隔离与重构（Fault Detection, Isolation, and Reconstruction，FDI/FTC）是机器人容错控制的经典框架~\cite{blanke2016diagnosis}。FDI 通过解析冗余、状态观测器或参数辨识检测系统中的故障并定位故障源；FTC 在检测到故障后通过控制律重构维持系统稳定。该框架在传感器漂移、执行器卡死等问题上有成熟应用，但应用于本文关注的"未知幅值的编码器系统性偏差"时存在三个关键局限：

\begin{itemize}
  \item \textbf{需要明确的故障模型}——本文涉及的"更换部件未重标"等偏差来源缺乏先验模型；
  \item \textbf{以"保持稳定"为目标}——\emph{经典 passive FTC} 检测后停机或退化运行；active FTC 虽追求性能保持但仍依赖明确故障模型，与本文"未知幅值加无故障模型"子问题不匹配；
  \item \textbf{对 episode 内恒定的隐变量偏差检测能力有限}——参数辨识类 FDI（如 RLS、UKF）原则上能在线估计恒定参数，但在缺少独立外部观测时存在不可辨识子空间（与\cref{prop:non_identifiable} 给出的平移对称性一致）。
\end{itemize}

\noindent Haddadin 等人~\cite{haddadin2017robot} 综述了机器人碰撞检测与隔离问题，亦集中在"碰撞事件"而非"碰撞后残留偏差"上。本文采用与 FDI/FTC 不同的路径——把偏差视为环境分布的一部分，让策略在训练时见过偏差从而在线适应，绕开"先检测、后切换"的两阶段范式。

\section{POMDP 求解方法}\label{sec:pomdp_methods}

部分可观测 MDP 的求解长期是强化学习~\cite{sutton2018reinforcement} 与序贯决策的核心难题。Kaelbling 等人~\cite{kaelbling1998planning} 提出基于信念状态的精确求解方法，将 POMDP 转化为信念空间上的 MDP 求解；这类方法在小规模离散问题上有理论保证，扩展到本文使用的高维连续状态空间需要近似（如点基 POMDP solver、深度变分信念）。Hausknecht 与 Stone~\cite{hausknecht2015deep} 提出深度循环 Q 网络（DRQN），用 RNN/LSTM 隐式记忆历史观测，在 Atari 等部分可观测任务上取得效果。把 episode 内恒定的隐变量偏差视作 \emph{static hidden parameter} 或 \emph{contextual MDP} 是处理本类问题的另一条线索（与本文随机偏差训练共享"训练时暴露多种参数"的基本思路，但显式建模隐变量需要额外的推断模块）。本文出于工程权衡（实现复杂度、超参敏感度、与现有 BC/RL 训练栈的兼容性）选择观测增强加端到端 RL 路径——通过引入独立外部观测使 POMDP 在信息论意义上近似还原为 MDP（详见\cref{sec:observability}）；上述其他路径原则上可解，作为 future work 在\cref{ch:conclusion} 提及。

\section{机器人强化学习与残差结构}\label{sec:residual_rl}

残差强化学习（Residual RL）由 Johannink 等人~\cite{johannink2019residual} 提出：先用一个手写的基础控制器完成大部分动作，再用 RL 学习一个残差策略对基础控制器输出做小幅修正。残差 RL 在很多机器人任务上能显著降低样本复杂度并提升训练稳定性，是 sim-to-real 领域常用的折中方案——把可解析建模的部分交给基础控制器，把难以建模的扰动交给 RL。

本文的编码器偏差恰好污染基础控制器使用的关节读数（雅可比与正运动学），残差 RL 在此场景下是否仍有效需要单独的实证分析；本文未在真机上做残差 RL 与 BC 加 HG-DAgger 的系统对照，留作未来工作（详见\cref{ch:conclusion}）。

\section{鲁棒强化学习与域随机化}\label{sec:robust_rl_dr}

域随机化（Domain Randomization，DR）是缩小 sim-to-real 差距的主流方案。Tobin 等人~\cite{tobin2017domain} 在物体姿态估计任务上提出视觉 DR——通过随机化纹理、光照、相机位姿等参数，使策略对视觉外观差异鲁棒；后续工作扩展到状态空间 DR（位置噪声、控制延迟、动力学参数），在轮足机器人、无人机等场景取得 sim-to-real 成功。

本文使用的"随机偏差训练"（详见\cref{sec:random_bias}）在形式上与 DR 同源——两者都依赖"训练时让策略见过部署分布的样本"这一基本思路，但需要指出两者在信息论上的本质区别：在 Tobin 等人原始 setting（姿态估计、抓取）中，随机化的视觉参数对策略而言是\emph{冗余变量}（应被忽略，策略学到的应是 invariance）；而本文随机化的偏差 $\vect{b}$ 是策略\emph{必须 condition} 的隐变量——按\cref{subsec:identifiability_vs_solvability} 的条件补偿要求，最优策略对不同 $\vect{b}$ 必须输出不同动作。两者在该 setting 下分别属于不变性学习与条件补偿学习两种相反的信息论范式，仅在"训练分布覆盖部署分布"这一表面思路上同源。状态空间 DR 在本文\cref{sec:backup_training} 备份策略训练中作为成熟方案被使用——位置噪声、速度抖动、检测延迟等低维状态扰动通过 DR 即可覆盖 sim-to-real gap，这与任务策略需要 BC 加 HG-DAgger 真机模仿的视觉路径形成对照。

\section{模仿学习与人在回路}\label{sec:il_hil}

模仿学习（Imitation Learning，IL）与强化学习（RL）的人在回路（Human-in-the-Loop，HIL）变体共同构成本文真机部署的方法基础。本节按两条平行支线综述—— IL 方向的 BC$\to$DAgger$\to$HG-DAgger 与 RL$+$HIL 方向的 RLPD$\to$HIL-SERL，最后给出本文双端选择的依据。

\paragraph{IL 支线：BC、DAgger、HG-DAgger}\textbf{行为克隆}（Behavior Cloning，BC）是最简的 IL 方法——在专家演示数据上做监督学习，把状态映射到动作。BC 实现简单、训练稳定，但在 OOD 状态下行为未定义（compounding error 问题），通常需要大量演示或额外正则化。Ross 等人提出的 \textbf{DAgger}（Dataset Aggregation）~\cite{ross2011dagger} 是经典改进——策略部署时在新状态上 query 专家、把专家动作合并入数据集重训，迭代直至收敛。DAgger 的关键限制是 query 由策略发起（query-by-policy）——在策略尚未稳定时频繁要求专家在意外状态下给出动作，对人类专家不友好。\textbf{HG-DAgger}（Human-Gated DAgger）~\cite{kelly2019hgdagger} 是 DAgger 的人类发起变种——介入触发由人决定（human-initiated）：操作员只在策略失败模式上介入，介入帧合并入下一轮重训。本文真机阶段采用 HG-DAgger 作为最终方案。

\paragraph{RL+HIL 支线：RLPD、HIL-SERL}\textbf{RLPD}~\cite{ball2023rlpd} 在 Soft Actor-Critic~\cite{haarnoja2018sac} 基础上加入离线演示缓冲区与在线缓冲区 50/50 混合采样，为稀疏奖励任务提供 demo 引导。\textbf{HIL-SERL}~\cite{luo2025hilserl} 在 RLPD 之上把人在回路干预作为持续训练数据源贯穿整个 online 阶段，干预转移与原始 demo 同等地位回注离线缓冲区。HIL-SERL 在 Luo 等人原文的多个真机操控任务上取得突出效果。\emph{本文的解读是}：HIL-SERL 的 SAC online 阶段需要较高真机吞吐量让 critic 通过持续 online interaction 在线 calibrate Q 表面（依据本文\cref{subsec:hilserl_failure} 的真机失败模式回推），该条件在低吞吐真机上不易满足。

\paragraph{本文双端选择}仿真侧采用 HIL-SERL（\cref{sec:sim_task_train}）——仿真吞吐量高、bias 注入可控，HIL-SERL 完整收敛并验证 H1–H3；真机侧改用 BC 加 HG-DAgger（\cref{sec:real_task_deploy}）——本文真机条件下 HIL-SERL SAC online 阶段 actor 解冻后大幅漂移（\cref{subsec:hilserl_failure} 详细复盘），HG-DAgger 不依赖 critic、调参面更小，在小数据真机场景显著更稳。这一选择由（观测模态 $\times$ 数据规模 $\times$ 硬件吞吐）三轴决定，是\cref{sec:contributions} 贡献 2 中范式选择决策原则的实例之一。

\section{安全强化学习与 Reward Hacking 背景}\label{sec:safe_rl}

安全强化学习关注在训练或部署过程中保证系统不违反安全约束。约束 MDP（Constrained MDP）与 CPO（Constrained Policy Optimization）等方法通过 Lagrangian 多项式或拒绝采样等技术显式处理约束。本文未直接采用约束 MDP——本文的安全需求（人机协同避让）通过\emph{分层结构}（任务策略 $+$ 备份策略 $+$ 运行时距离触发硬切换，详见\cref{sec:backup_paradigm}）而非约束优化实现，这更符合工业部署场景的工程可解释性需求。

Kiemel 等人~\cite{kiemel2024safe} 在工业机器人安全 RL 中提出\emph{非负即时奖励 $+$ 大终止惩罚}的奖励结构原则，用于训练 backup-as-safety-layer 的避让策略。本文\cref{sec:backup_reward} 备份策略奖励 V3 直接继承这一原则，并在 V1$\to$V2$\to$V3 三次迭代中实证了"奖励设计若不满足该原则，策略会通过 reward misspecification 找到设计意图之外的最优解"。

\textbf{Reward hacking} 概念指策略在最大化奖励信号的同时违背设计意图——典型表现是策略找到了"提升奖励但不真正完成任务"的捷径行为。Reward hacking 是奖励工程中的经典问题，在大型语言模型对齐与机器人 RL 领域均被广泛讨论。本文\cref{sec:backup_reward} V1（接近度奖励）与 V2（全负奖励）两次失败迭代提供了 reward misspecification 的两类典型表现（V2 兼具 termination-policy 偏置）；具体机制与训练曲线对照见\cref{sec:backup_reward}。
