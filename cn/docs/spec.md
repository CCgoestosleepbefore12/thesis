## 核心叙事线

> 编码器偏差把机器人操作问题从 MDP 变成 POMDP
> → **问题层面**：观测增强恢复可辨识性（信息充分），但偏差物理上仍在，策略必须以 $\vect{b}$ 为条件输出补偿
> → **任务策略**：HIL + RLPD 在真机上训练，应对视觉 sim2real gap 与偏差条件化补偿
> → **备份策略**：纯仿真 SAC + DR 迁移，为 HIL 训练提供人机安全保障
> → 两种 sim2real 范式因地制宜，由观测模态和任务特性决定

---

## 两个子系统的训练范式对比（核心架构决策）

这是论文的一个独立贡献点——**同一机器人系统里对不同子任务选用不同的 sim2real 范式**：

| 维度 | 任务策略 (Ch.4) | 备份策略 (Ch.5) |
|---|---|---|
| **观测模态** | 24D 状态 + 双相机 RGB (ResNet10) | 纯状态 (robot 18D + 障碍物 10D/个) |
| **训练算法** | RLPD + SAC | 纯 SAC |
| **训练场景** | HIL + 真机（含仿真预训练）| 纯仿真 |
| **Sim2Real 主要瓶颈** | **视觉域差距** | 低维状态噪声/延迟 |
| **为什么 DR 不够** | 渲染图像 vs 真实相机差距大，DR 难覆盖纹理/光照/噪声分布 | DR on 位置噪声/延迟/速度 范围可控 |
| **sim2real 路径** | HIL + 真机微调 | Domain Randomization |
| **人类介入** | 键盘干预，安全依赖 Ch.5 | 无 |
| **观测核心挑战** | 编码器偏差 $\vect{b}$ | 手部位置噪声+延迟 |

**依赖关系**：Ch.5 备份策略的存在是为了让 Ch.4 任务策略的 HIL 训练过程对人类安全——它是 Ch.4 训练范式的安全使能器。

### 第 5 章 纯仿真与域随机化的备份避障策略（7–8 页）

    - LINEAR / ARC / STOP_GO / PASSING

5.4 奖励函数设计演化（Reward Hacking 案例研究）
    - V1: proximity reward → 策略逃跑（典型 reward hacking）
    - V2: 全负奖励 → "快速死亡优于缓慢死亡"（奖励最优 ≠ 设计意图）

      · 为什么 V1 失败：奖励的最优解 ≠ 设计意图

    - 引用第 2 章 reward hacking 背景

5.5 面向 Sim-to-Real 的域随机化
    - 位置噪声 σ=3cm（MediaPipe + D455）
    - 速度噪声 σ=1cm/s（帧间差分）
    - 观测延迟 U(0, 2) 步

## 已确定的设计决策

| 决策 | 选择 | 原因 |
|---|---|---|
| 理论框架 | 标准 POMDP（不引入 HiP-MDP） | 术语通用，审稿人熟悉 |
| 可观测性分析严格度 | 严格命题 + 构造性证明 | 硕士论文需要理论深度，有消融实验验证 |
| 仿真注入实现 | 放第 3.5 节 | 属于建模层面的等价性问题 |
| 真机注入实现 | 放第 7.2 节 | 属于部署层面的工程问题 |
| 3.5 桥接方式 | 给出与实现无关的两个充分条件 | 统一仿真和真机的注入逻辑 |
| 偏差类型 | 固定/随机（episode 内恒定），排除漂移/噪声 | 恒定隐变量 vs 时变隐变量是不同 POMDP 结构 |
| **可辨识性 ≠ 可解性** | **3.4.3 专门小节澄清** | **回应读者质疑，为 Ch.4 随机偏差训练铺垫** |
| **方法对比小节（原 3.5）** | **删除，内容分流到 Ch.2 和 Ch.6** | **避免类别不匹配和超范围断言** |
| **Ch.4 训练范式** | **HIL + RLPD + 真机训练** | **视觉 sim2real gap 过大，纯仿真+DR 不可行** |
| **Ch.5 训练范式** | **纯仿真 SAC + DR** | **观测为低维状态，DR 足以覆盖 sim2real gap** |
| **Ch.4/Ch.5 范式对比** | **作为独立贡献点强调"因地制宜"** | **两种 sim2real 路径由观测模态决定，方法论观察** |
| Ch.5 POMDP 处理 | 轻提一句手部观测部分可观测，不做严格形式化 | DR 已覆盖观测退化，严格 POMDP 分析收益低 |

| 引用规范 | 每个引用必须有可核验的真实来源 | 已核实：Kana 2022、Gong 2000、Vocetka 2021、Haddadin 2017/2022、Blanke 2016、Siciliano 2010、Ott 2008、Sutton-Barto 2018、Kaelbling 1998、Hausknecht 2015、Johannink 2019、ISO 9283、libfranka |
