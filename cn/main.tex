% 修复 CJK 环境下 amsthm 证明环境末尾 QED 方框孤立成行的问题。
% 标准 amsthm 使用 \hfill 推 QED 到行末，这在 CJK 文字段末会被 ctex
% 的 fullwidth 处理打断，导致方框跳到新行。下面的重定义用 \unskip +
% \nobreak + \hspace*{\fill} 保证 QED 紧贴最后一个字符且不分行。
\makeatletter
\renewcommand{\qed}{%
  \unskip\nobreak\hspace*{\fill}\nobreak%
  \ensuremath{\square}%
}
